## Nothing here yet, on purpose

Psanctuary keeps its standard operating procedures in a private repository, where its people draft them and approve each
version with a tag. A procedure appears **here** only when an officer adds its path to that repository's allowlist; a
workflow then copies it in, after a check that stops anything private or secret-shaped. **The allowlist is empty until an
officer adds a path**, so today this README is the whole repository.

## Please do not edit this repository by hand

Everything that arrives is copied by the workflow, and the next copy replaces hand edits. The branch keeps a deletion-only
rule so the copy can always arrive. To suggest a change to a procedure, write to Psanctuary (below).
